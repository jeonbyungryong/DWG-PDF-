# AC09 AutoCAD 공통 실행 절차 — 2026-10-10

## 사용자 승인과 범위

사용자는 AC08 현재 PC AutoCAD 검증 결과를 전제로 최종 개발완료를 승인하고, AutoCAD의 실험적 문구·추가 확인창·설치 선택을 자동 반영하도록 요청했다. 이어 아래 GUI 흐름을 명시적으로 승인했다.

입력 방식 → DWG 파일/폴더 → PDF 출력 폴더 → CAD 종류 → 자동 변환 → 공통 완료 안내.

승인 기준은 현재 PC AutoCAD2021과 승인 템플릿이다. 새 AC09 실행본은 Codex가 Computer Use로 검증했으며, 사용자가 새 실행본을 직접 시험했다는 의미는 아니다. GstarCAD 실기 회귀는 `DEFERRED_USER`이며 다른 PC·다른 AutoCAD 버전의 지원 완료를 주장하지 않는다.

## 변경

- AutoCAD 선택창의 실험적 표시, 별도 실험적 확인창, 정상 변환 시 콘솔 경고 제거.
- 선택한 CAD 설치가 하나이면 자동 적용. GstarCAD에도 같은 단일 설치 정책 적용.
- 복수 AutoCAD 설치 중 유효한 저장 설정이 있는 설치가 하나이면 자동 선택. 같은 설치의 ProgID 별칭 전체를 검사하고 설치 단위로 판단.
- 복수 설치를 결정할 수 없을 때만 기존 설치 선택창 표시.
- 기존 TOML/PC3/설치 지문 검증과 성공한 설정 저장, 원본 보호·소유 CAD 정리·파일별 실패 격리 유지.
- 설정이 없거나 바뀐 경우의 TOML 선택, 실제 오류, 공통 완료 안내 유지.
- 직접 CLI의 `--allow-experimental-autocad`/설정의 `allow_experimental_autocad` 호환 필드는 유지. GUI의 AutoCAD 선택은 이 명시적 활성화를 자동 전달한다.

현재 PC 기본 `DWG TO PDF 실행` 바로가기는 새 실행본에 연결했다. `DWG TO PDF 실행 - 자동설정검증본`은 직전 AC08 실행본이며 `DWG TO PDF 실행 - 이전검증본`은 최초 사용자 수용 실행본이다. 이전 파일을 덮어쓰지 않았다. 실제 캐시 복구는 [AC08](AC08-EXPLORER-AUTO-CONFIG-2026-10-10.md)의 일반 사용자 실행 문맥과 설치/TOML/PC3 지문 확인을 따른다.
