# GC-02 — 현재 PC 검증 완료 범위와 다른 PC 인계

## 결론

2026-10-06 수행한 현재 PC의 자동 GstarCAD 검증과 검증용 frozen EXE 시험 결과를 정리한다. 제품 소스 기준은 `2f849b616c77b007aa43fa659576f462e12920b8`, 작업 브랜치는 `codex/gstarcad-main-regression`이다. 후속 좌표 비교 수정은 테스트 하네스에만 적용했다. 제품 변환 로직은 추가 변경하지 않았다.

현재 PC의 아래 자동 시험은 완료했지만, 전체 G3/G5·최신 AutoCAD 실기·다른 PC 수용·MAIN 통합·공식 릴리스 완료를 의미하지 않는다. [GC-01](GC-01-HANDOFF-2026-10-06.md)의 미완료 목록 중 전체 COM/native 비교와 현재 PC의 frozen 시험은 이 후속 결과로 갱신한다. 나머지 과거 기록은 보존한다.

실기 엔진은 GstarCAD 2026, 실제 COM Version `26.00`, 파일 버전 `26.3.0.0`이다. 기본 native43의 실제 추출 기록은 native 성공563회, 불가0회였다. 불가 주입 시험은 전송 경계의 테스트 주입이며 실제 CAD 보안 차단을 재현한 것은 아니다.

특수5개는 단일 APP 소유 CAD의 여러 도면 순차 처리, 잘못 저장된 창을 가진 학습 원본2개의 독립 영역 계산, 실제 구조 점수3개, 내부 Scale13종, 순차 플롯 및 수명주기 실패 정리를 포함한다. 헤더 오류 격리는 내부 손상 DWG·hang 복구 시험이 아니다.

모든 해당 수용 감사에서 원본 SHA-256·mtime, 기존 사용자 CAD 보존, APP 소유 CAD 종료를 확인했다. 실제 업무 도면7개에서도 APP 소유 CAD1개만 새로 관측했고 종료를 확인했다. 고객 파일·PDF·개인경로·PID·원시 로그는 공개 자료에 포함하지 않는다.

## 출력 및 성능 해석

- 승인43개 각각의 기대 축척·회전·출력창 오차0.001 도면 단위 미만을 대조했다.
- COM/native43쌍과 native/MC-02 기준43쌍은 144dpi RGB 렌더 픽셀이 동일했다. frozen43도 기준43쌍과 동일했다.
- 출력은 엄격 파싱 가능한 비암호화 단일 A4 가로(±0.2mm), `/Rotate=0`, 비공백이었다. 실제 업무 도면7개도 같은 PDF 구조 조건을 통과했다.
- 승인43개와 업무7개 전체 렌더의 도곽·표제란·방향을 개괄 검토했다. 이는 미세 글꼴·선굵기·치수 의미 정확성의 사용자 수용 증거가 아니다.
- `monochrome.ctb`를 유지하고 남는 색상은 허용한다. 완전 흑백이나 추가 RGB 보정을 수용 기준으로 요구하지 않는다.
- 평균은 배치 시간/입력 수이며 파일별 처리시간 측정이나 모든 도면의 속도 보장이 아니다. COM 전용과 기본 native 시간을 섞지 않는다.

## 좌표 비교 오탐 수정

기존 하네스의 완전 일치는 43개 중35개에서 창 좌표의 미세 부동소수점 차이로 실패할 수 있었다. 최대 차이는 `7.275957614183426e-12`였고 축척·회전43개는 정확히 동일했다. 승인 허용값은 `0.001` 미만이다.

하네스는 원본 파일 순서·결과 개수·단일 frame·축척·회전은 정확히 비교하고, 유한 창 좌표만 절대 차이 `<0.001`로 비교한다. 상대 오차나 제품 좌표 반올림은 도입하지 않았다. 신규 시험 RED→GREEN과 전체 pytest를 확인했다. 완료된 실제 COM/native 판정43쌍을 새 비교 함수에 재입력해 통과했으며, 이를 수정 후 라이브43 시험 재실행으로 표시하지 않는다.

## 실패 기록과 한계

- 최초 sandbox COM 실행은 기동 오류 `-2146959355`로 변환0건 실패했다. 일반 desktop 실행 재시험은 통과했다. 최초 실패 근거도 보존했다.
- frozen COM 첫 감사 도구는 CP949 로그를 UTF-8로 읽어 실패했다. 앱은 의도한1실패/1성공이었다. 로컬 감사 도구의 디코딩을 수정한 전체 재시험으로 최종 감사했다.
- 전체 pytest 첫 후속 실행은 Windows 공용 임시 폴더 접근 거부로 준비 오류371개가 발생했다. 작업공간의 새 임시 경로로 재실행한 결과가915 PASS/13 SKIP이다. 권한·보안 설정을 변경하지 않았다.
- 13 SKIP은 실기 환경 미지정9개와 symlink 권한4개이다. 관련 GstarCAD 특수 실기는 별도로 수행했으며 pytest SKIP를 PASS로 치환하지 않는다.
- 사용자는 문제 DWG가 GstarCAD에서도 열리지 않았다고 보고하고 GUI 추가 검증 생략을 요청했다. 사용자 보고와 Codex의 직접 관측을 구분한다. GUI 선택 창·전체 보고 창 수용은 사용자 요청으로 제외이며 자동 PASS가 아니다. 관측된 선택 창 문제의 원인을 DWG 손상으로 독립 입증한 것은 아니다. GUI 구현은 수정하지 않았다.

## 근거와 재현 기준

로컬 증거는 ignored `.pytest-tmp/gc2-*`의 JUnit, 결과 JSON, 원본 보호 감사, 전체 렌더와 종료코드이다. 공개 문서는 집계·방법·한계만 포함한다. 원시 고객 증거는 승인 없이 공유하지 않는다.

검증용 runtime ZIP: SHA-256 `1EB8F75E2CB7A3B5BC0F9A6BA5E553F279494CCAFC580447FACBE57AFA453268`, 43,275,468bytes. 이 ZIP은 제품 SHA `2f849b6`에서 만든 현재 PC 검증용이며 공식 릴리스가 아니다. 후속 테스트·문서 커밋은 runtime 코드에 포함되지 않는다. 패키지 내부 과거 문서보다 이 인계와 외부 안내를 우선한다.
