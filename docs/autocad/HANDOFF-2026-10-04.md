# MAIN 인계와 복구 — 2026-10-04

사용자는 현재 PC의 검증·수정·자료를 MAIN에 병합하여 원래 PC의 GstarCAD 회귀를 진행하도록 승인했다. 소스 통합 승인과 공식 지원·릴리스 승인을 구분한다. 기본 공급자는 GstarCAD이며 AutoCAD는 명시적인 실험적 opt-in이다.

## 현재 PC에서 끝낸 내용

AutoCAD 시작 대기, 장치 갱신 후 PaperUnits, LISP 신뢰 정책의 읽기 전용 확인과 fallback, 중복 PageMode 검증 호환, 전용 PC3, 실측 회전 보정, 작업용 도면 RGB·속성의 흑백 처리를 수정했다. 제품 기준 `4a62a38`에서 실제 AutoCAD 3 PASS와 86 출력·기대값을 확인했다. 관리자 회귀 813 PASS / 9 SKIP 및 링크 4 PASS를 확인했다.

병합 전 독립 검토에서 CLI 선택이 서비스 설정에 반영되지 않는 문제와 benchmark/frozen 후속 PDF 검증·인수 전달 문제를 발견해 수정했다. 재현 실패 후 수정된 집중 회귀 42 PASS, 독립 검토 35 PASS를 확인했다. 실제 CLI와 benchmark도 각각 1건 성공했다. 추가 COM busy 첫 실행의 실패와 원본·사용자 CAD 보존·소유 CAD 종료도 증거에 기록했다.

인계 도구와 병합 전 수정까지 포함한 전체 회귀 및 무결성 확인의 최신 수치는 [PC-B 증거](../../validation/autocad-2021-pc-b/README.md)를 따른다.

## 원래 PC의 다음 한 단계

새 폴더에 MAIN을 clone하고 [GstarCAD 회귀 절차](../../tools/regression/gstarcad/README.md)를 실행한다. 기존 checkout의 dirty 작업은 보존한다. 승인 입력 43개와 해시·기대값 manifest, 실기 3개 시험 및 86 출력 감사를 저장소에 포함했다.

GstarCAD 직접 실기·G3와 그 후 frozen EXE·G5는 NOT_RUN이다. 잘못된 저장창 시험 등 원래 PC의 승인 자료가 필요한 특수 시험과 육안 문자·선굵기 확인을 별도로 수행한다.

- 병합 전 MAIN: `backup/main-before-autocad-pc-20261004`, SHA `de4bc247d7363c440d05aa5c949cc59df3e6f5ca`.
- 현재 PC 실기 검증 제품: `backup/autocad-pc-validated-20261004`, SHA `4a62a384ea12c760106015605fd67c2f9e5a9916`.
- 전체 인계 최종 코드: `codex/autocad-pc-validation` 및 최종 PR의 head. 브랜치를 삭제하지 않고 보존한다.
- 로컬 전체 Git bundle과 작업 자료 ZIP은 공개 저장소와 독립적으로 보관한다. 사본에서 clone·checkout과 파일 해시 검사를 수행한 결과를 로컬 인계 보고서에 기록한다.

GitHub 보존 참조에는 제품 코드와 승인된 공개 증거가 있다. 개인 원시 로그·실행 설정은 로컬 ZIP에 보관한다. 로컬 ZIP은 같은 PC 디스크에 있으므로 디스크 고장에 대비하려면 별도 저장매체에 복사해야 한다.

## 문제가 발생했을 때

현재 MAIN을 강제 reset·force-push하지 않는다. 기존 도면과 다른 작업자의 변경을 보존한다. 병합을 취소하려면 새 분기에서 해당 PR의 merge SHA를 지정해 revert한다.

```powershell
 git fetch origin
 git switch -c codex/revert-autocad-pc origin/main
 git revert -m 1 <해당_PR_merge_SHA>
 # 복구 변경을 검토·시험한 뒤 PR로 MAIN에 반영한다.
```

코드만 별도 복구하려면 새 폴더에서 보존 브랜치를 clone하거나 Git bundle을 clone한다. 공개 보존 브랜치와 로컬 전체 자료를 함께 사용하면 이 PC의 작업을 다시 구성할 수 있다.
