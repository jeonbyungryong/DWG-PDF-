# GUI-01 — 탐색기형 경로 선택 구현 및 검증 인계

## 결론

승인된 [명세](../superpowers/specs/2026-10-07-explorer-path-picker-design.md)와 [계획](../superpowers/plans/2026-10-07-explorer-path-picker.md)에 따라 세 경로 선택을 Windows Common Item Dialog로 교체했다. 제품 소스 기준은 `2918308cc07341615484d19868d051e4c77ebc03`, 브랜치는 `codex/gstarcad-main-regression`이다.

코드·번들·변환 엔진 검증은 아래 근거로 통과했다. **GUI 실기 수용은 BLOCKED**다. Computer Use 초기화 실패 때문에 새 EXE의 창 표시, 주소 표시줄 복사/붙여넣기, 선택 결과, 실제 취소를 관측하지 못했다. 따라서 GUI-01 전체 완료나 공식 배포 가능을 주장하지 않는다.

## 변경 내용과 분석

`windows_picker.py`가 표준 라이브러리 ctypes로 STA COM과 `IFileOpenDialog`를 호출한다. 파일은 DWG 필터·다중 선택, 폴더는 `FOS_PICKFOLDERS` 단일 선택이다. 기본 옵션을 유지하되 폴더의 파일 전용/다중 선택 충돌 옵션을 제거한다. 실제 파일시스템 경로를 Unicode로 직접 전달한다.

`HRESULT_FROM_WIN32(ERROR_CANCELLED)`만 빈 결과로 처리하고 다른 실패는 OSError로 전달한다. 인터페이스·할당 문자열을 해제하며 성공한 COM 초기화만 균형 있게 해제한다. 모듈 import는 DLL/COM을 초기화하지 않는다. 새 외부 의존성 및 패키징 명세 변경은 없다.

CAD 설치 목록용 기존 PowerShell 선택은 변경하지 않았다. 축척/회전/템플릿/플롯/변환 엔진/단일APP소유CAD/원본 보호/파일별 실패 격리도 변경하지 않았다. 이번 시간 차이는 단순 관측값이며 성능 개선의 인과 근거가 아니다.

## 실패·재시도·판단

- Windows 샌드박스 전체 시험: 97 실패/835 통과/12 SKIP. 첫 실패의 원인은 임시 파일 strict resolve의 WinError5였다. 제품을 수정하지 않고 일반 실행으로 재시험하여 931/13을 확인했다. 별도 진단에서 PYTHONPATH의 pywin32 하위 디렉터리 누락도 확인하고 기존 의존 경로를 복구했다.
- Computer Use: `CreateProcessWithLogonW failed:1056`, 세션 reset 후 `apply deny-read ACLs` 초기화 실패. 대체 GUI 입력 방식으로 우회하지 않았다.
- Bash 장부 도구의 dirname/basename 부재로 계획 전용 장부를 apply_patch로 직접 유지했다. 수동 장부 누락 위험이 있으나 제품 영향은 없다. 기존 증거 보존 요구에 따라 장부를 삭제하지 않는다.
- 실제 GUI 두 배치 대신 CLI 두 배치로 변환 엔진만 검증했다. 이는 안전한 영향 범위 검증이며 GUI 완료의 대체 근거가 아니다.
- 최종 리뷰 경미 항목1건 보류: 출력 포인터 할당 직후 실패, 두 번째 파일 실패, SetFileTypes 실패에 대한 시험 보강. 현재 finally 해제 구현의 결함/누수는 발견되지 않았다.

## 남은 작업/실행안

1. Computer Use 연결을 복구한 뒤 새 EXE의 DWG 파일/입력 폴더/출력 폴더 창을 실제 관측한다. 세 주소 표시줄에서 경로 복사·붙여넣기·이동과 각 단계 취소를 검증한다. 취소 시 CAD 미기동을 확인한다.
2. 새 EXE GUI의 폴더/다중 파일 입력으로 승인 ESS7 변환을 각각 실행하고 원본/기존 CAD/소유 CAD 정리와 PDF를 다시 확인한다. 완료 전 새 출력 경로를 사용한다.
3. 다른 PC·최신 AutoCAD 실기, 설치본 교체, MAIN 통합, 공식 릴리스는 **NOT_RUN/별도 승인**이다. 과거 GC-02 배포 키트는 새 GUI 번들로 바뀐 것으로 간주하지 않는다.

구현은 요청된6.1 SOL/Medium으로 수행했고 최종 읽기 전용 리뷰에만 사전 고지한 Astra/High를 사용했다.
