# AutoCAD 확장 작업 분해 / 검토용 로드맵

명세: [REV01](../superpowers/specs/2026-10-02-autocad-support-design.md)

상세 계획: [T1~T9 구현/검증 계획](../superpowers/plans/2026-10-02-autocad-support.md). G0 승인 완료, AC-01 산출물 작성 완료/G1 검토 대기. AC-02 이후 제품 구현은 아직 시작하지 않았다.

이 문서는 업무 범위와 완료 기준이다. **상세 구현 계획이나 착수 승인이 아니다.** 현재 담당자·진행 상태·다음 작업은 [개발 허브](README.md)에 연결된 관리 이슈에서 확인한다.

AC-02~05는 AutoCAD 미설치 환경에서도 일부 진행할 수 있으나, GstarCAD 실제 회귀에는 해당 실행환경이 필요하다. AC-06~07은 AutoCAD 환경이 없으면 BLOCKED_ENVIRONMENT이며 앞 작업의 코드 PASS로 대체하지 않는다.

## 상세 계획 작성 시 필수 항목

- 작업마다 소유 파일·소비/제공 인터페이스·오류 의미·의존성을 고정한다.
- 실패 테스트 → 실패 확인 → 최소 구현 → 통과 확인 → 독립 리뷰 → 커밋 순서를 둔다.
- 현재 타입 강결합(`GstarDocument`),전용 프로세스 이름,제품별 plot/media/PDF 보정을 확인한다.
- 기존 GstarCAD 테스트를 이름만 바꿔 통과시키지 말고 보호 계약이 유지되는지 검사한다.
- AutoCAD 실기 테스트는 opt-in으로 분리하고 환경이 없을 때 SKIP/NOT_RUN 사유를 남긴다.
- 상태별 사용자 문구,CLI 비대화형 동작,구 설정 충돌 정책을 명세와 일치시킨다.

## 증거 제출 형식

각 작업은 커밋/PR,실행 명령,환경,총PASS/FAIL/SKIP,NOT_RUN 목록,변경 파일,회귀 영향,남은 위험을 관리 이슈에 기록한다. 고객 DWG·개인 로그 대신 승인된 표본 ID와 비식별 요약/해시를 사용한다.
