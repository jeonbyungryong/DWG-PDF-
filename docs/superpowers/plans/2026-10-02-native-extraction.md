# CAD 내부 일괄 추출 및 출력 오류 수정

승인: 사용자 "진행해". 기존 Antigravity agy/dwg-pdf-performance 작업트리 사용.

1. LISP가 APP 소유 CAD의 현재 작업 복사본에서 필터된 객체와 도달한 블록 정의를 JSON으로 일괄 추출하는 시제품. 원본은 수정하지 않는다.
2. 응답 nonce/문서/크기/완결성 검증, 기존 GstarDocument 검증·좌표 합성 재사용. 기존 COM 방식과 동일 입력에서 판정/PDF/시간 비교.
3. 효과가 확인되면 변환 경로 및 실행 번들에 통합. 등록 경로는 기존 스냅샷 유지.
4. Scale 공란/N/A는 구조로 후보 프로파일을 정한 후 해당 값 셀을 검증한다. 잘못된 값과 중복 값은 보수적으로 거부한다.
5. 90/270도 출력은 실제 CAD 출력과 렌더 방향을 확인해 수정한다. 원본 변경·종료 범위 보호.
6. 13개 템플릿, 변형 입력, 전체 자동화 테스트, 배포 EXE 검증 후 결과와 한계를 보고한다.

1차 가설: 외부 COM의 속성별 호출이 탐색15.19초의 주 비용이다. 동일 속성 수집을 CAD 내부에서 수행하면 통신 비용을 줄이면서 기존 판정을 재사용할 수 있다.
