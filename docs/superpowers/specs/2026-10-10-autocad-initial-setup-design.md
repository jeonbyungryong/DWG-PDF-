# AC11 AutoCAD 초기 설정 자동화 — 기획·명세 REV1

상태: **문서 검토 대기 / 제품 구현 미착수**. 2026-10-10, Codex / PC-B.

## 1. 목적과 현재 상황

새 PC에서 GitHub 실행 ZIP을 받은 사용자가 TOML 선택창에서 종료했다. 이는 저장 실패가 입증된 사례가 아니라, 기존 최초 수동 설정을 끝내지 않은 사례다. 이번 기능은 **정상 설치된 AutoCAD의 첫 실행부터 TOML 선택·편집과 PC3 수동 복사 없이 변환**할 수 있게 한다.

기준 MAIN: `fb580e03f379be7963ebdfeafd1d76633edb36c3`. 기존 Release: `windows-autocad-final-20261010`. 작업 브랜치: `codex/ac11-autocad-initial-setup-20261010`. 기존 Release와 백업은 보존한다.

## 2. 필요한 변경만 수행

| 포함 | 제외 |
|---|---|
| AutoCAD 첫 설정의 자동 조회·검증·로컬 생성 | CAD 설치·라이선스 활성화·COM 등록 자동 수리 |
| 기존 GUI에서 TOML 선택 제거, 정상 저장 설정 재사용 | 새 설정 관리 화면·설치 마법사·MSI·업데이트 서비스 |
| 현지 PC3 사본과 검증된 A4 이름 저장 | 개인 PC3·설정·고객 도면의 공개 배포 |
| 단위 회귀, 현재 PC의 새 사용자 저장소 조건과 frozen GUI 시험 | 모든 AutoCAD 버전 인증, 이번 GstarCAD 실기 |
| 사용 안내·새 실행 ZIP·복구 백업 | 세션·플롯·형상·보안·timeout의 일괄 재설계 |

Windows x64, 정상 설치·라이선스·최초 초기화를 마친 일반 AutoCAD가 전제다. LT·수직 제품·불명확한 등록은 기존 거부를 유지한다. GstarCAD 경로와 실기 연기 상태는 유지한다.

## 3. 사용자 흐름

입력 방식 → DWG 파일/폴더 → 출력 폴더 → CAD 종류 → 필요 시 최초 자동 설정 → 변환 → 공통 완료 안내.

1. 기존 지문 검증을 통과한 AutoCAD 설정이 있으면 그대로 사용한다. 이 경우 설정 조회용 CAD 세션을 추가로 열지 않는다.
2. 유효 설정이 없으면 선택한 설치에서 초기 설정을 자동 준비한다. **TOML 파일 선택창은 표시하지 않는다.**
3. 단일 설치의 자동 선택, 유효 저장 설정을 가진 설치가 하나일 때의 자동 선택, 복수 설치의 기존 선택 규칙을 유지한다.
4. 출력 오류·설정 준비 오류는 기존 공통 안내와 콘솔 오류 코드로 알린다. 오류를 성공으로 표시하거나 다른 CAD로 자동 우회하지 않는다.

## 4. 초기 설정 생성 규칙

### 4.1 현지 CAD·플로터 확인

- 기존 `AutoCADSession`으로 소유권이 증명된 프로세스를 생성한다. 사용자 CAD에 연결하지 않는다.
- 기준 프로파일의 해시를 검증한 승인 템플릿 하나를 `SourceWorkspace`로 복사하고, 기존 `working_document()` 경계에서만 임시 도면을 연다. 사용자 입력 도면을 설정 조회용으로 사용하지 않는다.
- `Application.Preferences.Files.PrinterConfigPath`를 읽어 해당 검색 경로의 `DWG To PDF.pc3`를 찾는다. 같은 실제 파일을 가리키는 중복 경로는 하나로 취급한다. 파일이 없거나 서로 다른 실제 파일 후보가 여러 개라면 E210으로 중단한다. 임의 전역 디스크 검색은 하지 않는다.
- 실제 임시 도면에서 플로터와 `monochrome.ctb` 존재를 확인한다. 기존 `require_plot_environment()`로 용지를 검사한다. CAD 검색 경로나 개인 환경설정은 쓰지 않는다.
- 우선 이름은 `ISO_full_bleed_A4_(297.00_x_210.00_MM)` 하나다. 이름이 있어도 실측 크기를 검사한다. 이름이 없으면 기존 규칙에 따라 실측 A4 후보가 하나일 때만 채택하고, 모호하면 E211로 중단한다. 목록의 첫 항목을 임의로 선택하지 않는다.
- 크기 허용 오차는 기존 **0.20mm**이며 A4의 297×210 또는 210×297 후보를 확인한다. 최종 출력은 기존 **297×210mm A4 가로** 검증을 유지한다.
- 초기 조회 세션은 변환 세션을 열기 전에 종료한다. 동시에 존재하는 프로그램 소유 CAD 세션은 하나로 제한한다. 임시 도면은 저장하지 않는다.

### 4.2 파일 생성·재사용

- 현재 실행 사용자 환경의 `%LOCALAPPDATA%/DWG-to-PDF/autocad-auto/<고유 준비 ID>/` 아래에 PC3 사본과 `AutoCAD.toml`을 만든다. 프로그램 압축 해제 위치가 읽기 전용이어도 사용할 수 있어야 한다.
- 기존 개인 TOML·PC3·기존 자동 설정을 덮어쓰거나 이동하지 않는다. 원본 PC3의 조회 전후와 사본 해시가 같을 때만 생성 결과를 사용한다.
- 설정의 값은 기존 정책과 동일하게 고정한다: `provider="autocad"`, 선택한 실제 ProgID, 호환 활성화 `true`, 자동 매칭 `true`, native 추출 `true`, threshold/gap `1.0`, target saved window `false`, `DWG To PDF.pc3`, `monochrome.ctb`, 297×210mm. PC3 절대 경로와 실제 검증된 용지 이름만 현지 결과를 넣는다. native 제한 정책을 낮추지 않는다.
- 생성한 TOML을 기존 `load_config()`로 다시 검사한 뒤 기존 CLI의 `--config`에 전달한다. CLI 명시적 `--config` 사용은 유지한다.
- 기존 성공 후 기억 정책을 유지한다: 배치 종료0이고 TOML·PC3가 변하지 않았을 때만 설치 지문과 설정을 기억한다. 실패 시 다음 실행도 자동 준비하며 TOML 선택으로 되돌리지 않는다.
- 생성 중 실패하면 이번 준비가 소유한 파일만 정리한다. 생성 후 변환 실패 시 준비 파일은 로컬 진단용으로 보존할 수 있으나, 성공 캐시로 등록하지 않는다. 자동 전역 청소 기능은 추가하지 않는다.
- 파일·설치 변경으로 저장 지문이 무효이면 새로운 설정을 자동 준비한다. 기존 파일을 그대로 남긴다. 이전 custom 설정이 유효하면 계속 우선 사용한다.

## 6. 완료 판정

| 요구 | 증거 |
|---|---|
| 새 저장소 조건에서 TOML 선택 없이 준비·변환 | 단위 RED→GREEN, 실제 새 사용자 저장소 조건의 frozen GUI 최초 실행 |
| 재실행 자동 적용 | 완전 종료 후 같은 실행 경로 재실행; 추가 설정 준비가 없는지 확인 |
| 잘못된·모호한 환경 거부 | PC3/CTB 누락, A4 없음/복수/허위 이름·크기, 접근 오류·변경 중 해시 불일치 시험 |
| 사용자 자료 보호 | 승인 DWG·PC3·기존 설정의 SHA/mtime, 기존 사용자 CAD 보호 확인 |
| 세션 종료 | 소유 프로세스의 정확한 핸들 대기와 잔류 확인; PID 열거 1회만으로 판정하지 않음 |
| 기존 기능 유지 | 전체 pytest, GstarCAD 모의 경로·기존 캐시/별칭·CLI 회귀 |
| 사용 가능한 전달본 | 새 ZIP 전체 해시/CRC·압축 해제 self-check, 설치 안내, 백업 확인 |

다른 물리 PC의 실기는 별도 현지 실행 증거가 필요하다. 현재 PC의 새 저장소 시험을 타PC 실기 통과로 표기하지 않는다. 실제 다른 PC 시험을 못 하면 NOT_RUN과 다음 현지 확인 절차를 함께 인계한다.

## 7. 사전 조사와 승인

- 기준 전체 pytest: **986 PASS/13 SKIP,43.56초,exit0**. 별도 CAD 통합9건과 현재 권한 symlink4건 제외.
- 기존 설정·GUI 집중 재시험: **29 PASS,0.38초**.
- 사전 CAD API 조회는 PC3/CTB/A4 조회 이후 종료 직후 PID 확인에서 실패했다. 전체 PASS로 취급하지 않는다. 후속 읽기 전용 조회에서는 acad 프로세스가 없었다. 정확한 종료 시점/원인은 아직 확정하지 않았으며 종료 확인 방법을 검증에 포함한다. 제품 수정은 없었다.
- [Autodesk PrinterConfigPath](https://help.autodesk.com/cloudhelp/2024/ENU/AutoCAD-ActiveX-Reference/files/GUID-796FC8E9-DCB8-41D4-A0C4-E3ED2052D4C3.htm), [GetCanonicalMediaNames](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-ActiveX-Reference/files/GUID-BDFDA2F3-63E6-47CD-8185-1793BEEDBCB1.htm)의 공식 API를 사용한다.
